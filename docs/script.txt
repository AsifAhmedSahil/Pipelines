AI Engineering শিখতে চান, কিন্তু শুরু করবেন LLM দিয়ে, RAG দিয়ে, নাকি Agentic AI দিয়ে? কোথা থেকে শুরু করবেন আর কোনটার পর কোনটা শিখবেন, এই video-তে পুরো roadmap দেখাব। আর Agentic AI এই roadmap-এর কোথায় আছে, সেটাও বুঝতে পারবেন। আমি Asif, একজন Applied AI Engineer। এই channel-এ আমি AI Engineering-এর বিভিন্ন concept, practical example আর project নিয়ে কথা বলব। কীভাবে AI system তৈরি করতে হয়, কীভাবে test করতে হয়, আর কীভাবে real-world application-এ ব্যবহার করতে হয়, সেগুলো step by step দেখাব। কোনো কিছুতে limitation থাকলে সেটাও বলব। সহজভাবে বললে, AI Engineering হলো AI model আর বিভিন্ন engineering tool ব্যবহার করে বাস্তবে কাজে লাগে এমন reliable AI system তৈরি করা। এর মধ্যে data, retrieval, tool calling, evaluation থেকে শুরু করে deployment পর্যন্ত অনেক কিছু আছে। পুরো বিষয়টাকে আমরা পাঁচটা stage-এ ভাগ করে দেখতে পারি। প্রথম stage, LLM Fundamentals। এখানে আমরা বুঝব LLM আসলে কীভাবে কাজ করে। এর একটা মূল concept হলো next-token prediction। সহজভাবে বললে, model আগের context দেখে পরের token কী হতে পারে, সেটা predict করে। এর সাথে token, context window আর prompt-এর মতো বিষয়গুলোও বুঝতে হবে। এদিক থেকেই hallucination-এর বিষয়টা আসে। অনেক সময় AI-এর উত্তর শুনতে একদম ঠিক মনে হয়, কিন্তু তথ্যটা ভুল হতে পারে। তাই শুধু model-এর উত্তরের ওপর নির্ভর না করে দরকার হলে সঠিক information দিয়ে ground করতে হয় এবং verify করতে হয়। LLM ভালোভাবে বুঝতে পারলে পরের বিষয়গুলো শেখাও অনেক সহজ হবে। দ্বিতীয় stage, AI Application Development। এবার আমরা LLM দিয়ে actual application তৈরি করব। কীভাবে ভালো prompt লিখতে হয়, আর model-এর কাছ থেকে নির্দিষ্ট JSON format-এ response নিতে হয়, সেগুলো শিখব। এরপর আসবে function calling বা tool calling। এখানে model নিজে কোনো function execute করে না। বরং কোন function ব্যবহার করতে হবে, কী information দিতে হবে, সেটা বলে। তারপর আপনার application সেই function চালায়। এর পাশাপাশি backend-এর সাথে integration, error handling এবং conversation history কীভাবে manage করতে হয়, সেগুলোও শিখব। তৃতীয় stage, RAG Engineering। ধরুন, আপনার কাছে অনেকগুলো PDF document আছে। আপনি চান AI যেন ওই document থেকে information খুঁজে আপনার প্রশ্নের উত্তর দেয়। কিন্তু LLM তো আপনার private document আগে থেকেই জানে না। এখানেই RAG কাজে আসে। আমরা document-গুলোকে ছোট ছোট chunk-এ ভাগ করি, সেগুলোর embedding তৈরি করি, তারপর user প্রশ্ন করলে relevant information খুঁজে বের করে model-কে দিই। এতে model আরও relevant context পায় এবং ভুল উত্তর কমাতে সাহায্য করে। তবে RAG থাকলেই যে সব উত্তর সঠিক হবে, এমন না। ভুল information retrieve হলে উত্তরও ভুল হতে পারে। RAG নিজেই একটা গুরুত্বপূর্ণ engineering skill। আবার কোনো AI agent-এর document থেকে information খোঁজার দরকার হলে RAG-কে একটা tool হিসেবেও ব্যবহার করা যায়। চতুর্থ stage, Agentic AI। এখানেই AI system শুধু response দেওয়ার বাইরে গিয়ে বিভিন্ন কাজের পরবর্তী step নিজে ঠিক করতে পারে। সাধারণ AI application-এ developer আগে থেকেই workflow তৈরি করে দেয়। কোন কাজের পর কোন কাজ হবে, কখন model call হবে, কখন function চলবে, এগুলো application-এর code-এ ঠিক করা থাকে। কিন্তু Agentic AI-তে model পরিস্থিতি বুঝে পরের action বা tool কোনটা ব্যবহার করবে, সেটা বেছে নিতে পারে। অবশ্যই developer আগেই ঠিক করে দেয় agent কী কী করতে পারবে, আর কোথায় থামতে হবে। একটা agent সাধারণত একটা cycle-এ কাজ করে। প্রথমে action ঠিক করে, তারপর tool ব্যবহার করে, সেই tool-এর result দেখে আবার পরের step ঠিক করে। এভাবে প্রয়োজন অনুযায়ী একাধিক step-এ কাজ করতে পারে। এখানে planning, state আর memory-এর মতো বিষয়গুলো আসে। তবে একটা কথা মনে রাখবেন, শুধু tool call করলেই সেটা AI agent হয়ে যায় না। আবার সব agent-এর long-term memory বা multi-agent system-ও দরকার হয় না। এই stage-এ LangGraph আর MCP-এর মতো technology-র সাথে পরিচিত হবেন। LangGraph ব্যবহার করা হয় agent workflow তৈরি ও manage করার জন্য। আর MCP হলো AI application-এর সাথে external tool ও data connect করার একটা protocol। আর গুরুত্বপূর্ণ কোনো action নেওয়ার আগে মানুষের approval দরকার হলে Human-in-the-Loop ব্যবহার করা যায়। তবে Agentic AI-ই পুরো AI Engineering না। এটা পুরো roadmap-এর একটা গুরুত্বপূর্ণ অংশ মাত্র। পঞ্চম stage, Production AI Engineering। এবার তৈরি করা application-কে real-world-এ চালানোর পালা। এখানে শুধু application কাজ করছে কি না, সেটাই দেখলে হবে না। System-এর ভেতরে কী হচ্ছে, কোথায় error হচ্ছে, কত খরচ হচ্ছে, response দিতে কত সময় লাগছে, সবকিছু দেখতে হবে। এজন্য logging, monitoring আর observability দরকার। পাশাপাশি security, data protection আর reliability নিয়েও কাজ করতে হয়। আর evaluation শুধু এই শেষ stage-এ এসে শুরু হয় না। আপনি যখনই prompt, model বা RAG system-এ কোনো পরিবর্তন করবেন, তখনই test করে দেখতে হবে আগের চেয়ে ভালো হয়েছে, নাকি খারাপ। পুরো development process জুড়েই evaluation চলতে থাকে। আর এই roadmap ধরে এই channel-এ আমরা শুরু করতে যাচ্ছি আমাদের নতুন series, Build Your First AI Agent — From Zero to Production। এখানে একদম শুরু থেকে ধাপে ধাপে একটা AI agent তৈরি করব। Python basics, HTTP ও API, JSON, environment variable আর একটা basic LLM API call সম্পর্কে ধারণা থাকলেই আমাদের সাথে শুরু করতে পারবেন। এরপর একে একে tool calling, state, LangGraph, MCP, evaluation থেকে শুরু করে deployment পর্যন্ত সবকিছু practical project-এর মাধ্যমে শিখব। আর
